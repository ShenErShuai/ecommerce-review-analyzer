## 详细说明

```text
AI评论洞察帮你把商品页上的评论，直接变成能用的运营结论。

打开淘宝、天猫或京东的商品页，点一下插件，它会读取你当前页面上已经显示出来的评论，
然后调用你自己配置的 AI 服务，输出四块结果：

· 好评卖点 —— 买家真正满意的点，可直接用于详情页和投放文案
· 差评痛点 —— 集中吐槽的问题，优先改这些
· 用户画像 —— 谁在买、为什么买
· 改进建议 —— 产品与服务的具体优化方向

【自带 Key，用量透明】
本插件采用 BYOK（Bring Your Own Key）模式：你填自己的 AI API Key，
调用费用直接结算给 AI 服务商，插件不加价、不抽成、不代管你的额度。

【免费与 Pro】
免费版每天可分析 3 次，功能完整。
Pro 为一次性买断，解锁：
· 不限分析次数
· 导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）
· 客服回复模板，差评可直接照着回
· 手动翻页后合并多页评论再分析

【关于数据】
· 只读取你当前页面上已经可见的评论
· 不会自动登录、不会自动翻页、不会在后台持续运行
· 不读取订单、地址、支付信息或账号密码
· API Key 只存在你本机浏览器里，开发者没有服务器，也收不到你的任何数据

【适合谁】
· 电商运营与店铺客服：快速定位差评原因，批量产出回复
· 选品与采购：看竞品评论决定要不要上
· 产品经理：从真实反馈里找改进优先级

安装后请先在设置里填入 AI API Key，再打开商品页使用。
```

## 权限说明（Privacy practices 逐条填写）

审核时每条权限都要给出用途，直接用下面这几句。

| 权限 | 提交时填写的理由 |
|---|---|
| `activeTab` | 用户点击插件时读取当前商品页，用于识别平台并提取页面上已显示的评论 |
| `storage` | 在本地保存用户的 AI API Key、插件设置与当日使用次数 |
| `scripting` | 向商品页注入提取脚本，读取页面上已渲染的评论文本 |
| `windows` | 打开支付服务商（艺爪付费）的开通窗口 |
| 淘宝 / 天猫 / 京东域名 | 插件支持的商品页范围，仅在这些站点提取评论 |
| `api.deepseek.com` | 使用用户自己的 API Key 调用 AI 完成分析 |
| `revenue.ezboti.com` | 开通 Pro 与校验会员状态 |

**远程代码**：选「否，不使用远程代码」。全部逻辑都打进扩展包。

**数据用途**：勾选「网站内容」，并声明不出售、不转让给第三方、不用于与核心功能无关的用途、不用于信用评估。

## 隐私政策托管

`store/privacy.html` 已写好，需要一个公开可访问的地址。项目开源在 GitHub 后，最省事的路径：

1. 仓库 Settings → Pages，Source 选分支根目录
2. 拿到形如 `https://<用户名>.github.io/<仓库名>/store/privacy.html` 的地址
3. 填进商店的 Privacy policy URL，并把邮箱补进 `privacy.html` 第 8 节

也可以直接托管到任意已有的静态站点或对象存储，只要 URL 公开可访问、不需要登录即可。
