AI评论洞察 隐私政策

最后更新：2026-09-15  |  适用版本：0.1.0 起

AI评论洞察（以下称「本插件」）是一款 Chrome 扩展，用于提取电商商品页上用户当前已经看到的评论，并调用用户自己配置的 AI 服务完成分析。本政策说明本插件如何处理数据。

1. 开发者不运营任何业务后端

本插件没有开发者自己的服务器。评论内容、AI API Key、浏览记录都不会发送给开发者，也不存在开发者侧的数据库或日志。

2. 评论如何被处理

只有在用户主动点击「提取并分析」后，本插件才会读取当前标签页 DOM 中已渲染的评论文本，在本地整理后，直接从浏览器发送到用户自己填写的 AI 服务商接口。本插件不会自动登录、不会自动翻页、不会在后台持续抓取，也不会读取用户的订单、收货地址、支付信息或账号密码。

3. 本地存储的数据

数据存放位置用途
AI API Keychrome.storage.local调用用户自己的 AI 服务

以上数据仅保存在用户本机浏览器内，不会上传。卸载插件或清除浏览器数据即会一并删除。

4. 第三方服务

AI 服务商（当前为 DeepSeek）：用户点击分析时，评论文本会发送到该服务商完成分析。该服务商如何处理这些内容，适用其自身的隐私政策。用户可以选择不填写 API Key，此时插件不会发送任何内容。

艺爪付费：仅在用户主动点击「开通 Pro」或查询会员状态时使用，用于处理支付和会员校验。为此会传输一个由浏览器本地生成的匿名设备标识，用来把已购买的权益关联到当前浏览器；该标识不包含姓名、手机号、邮箱等个人身份信息。支付流程由艺爪及其支付渠道完成，本插件不接触、不存储任何银行卡或支付账号信息。参见 艺爪付费文档。

6. 儿童

本插件面向商家与运营人员，不针对 13 岁以下儿童，也不刻意收集其信息。

7. 政策变更

本政策如有变更，会更新本页顶部的日期。涉及数据处理方式的实质变更，会同时在扩展更新说明中标注。
